# Private workspace

Keep complete working transcripts, lawfully accessed local audio/video, downloaded subtitles, intermediate model output, and collection working files here. Everything except this README is gitignored. This boundary reduces accidental republication; it is not a security control or permission to obtain material unlawfully.

Never store credentials or cookies in repository files. Do not copy complete transcripts or media into `public-data/`; publish only permitted metadata, timestamps, limited excerpts, annotations, hashes, and review status.
