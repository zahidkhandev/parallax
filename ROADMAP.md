# Roadmap

## Phase 1 — Evidence inventory

- Import the existing NEET 2026 media workbook
- Deduplicate source URLs
- Verify outlet, title and publication metadata
- Separate packaging-only records from spoken evidence
- Mark mixed streams and unresolved records

## Phase 2 — Transcript workflow

- Define transcript-provider interfaces
- Import available lawful captions
- Add local transcription support
- Store complete working transcripts outside the public repository
- Generate transcript manifests and hashes

## Phase 3 — Annotation

- Segment speaker turns
- Identify target entities
- Apply claim and certainty labels
- Apply framing categories
- Add human review and second-review states

## Phase 4 — Analysis

- Calculate target-direction profiles
- Calculate source and speaker representation
- Calculate topic-attention distribution
- Calculate packaging-body relationship
- Publish evidence-quality indicators

## Phase 5 — Dashboard

- Build reproducible Kaggle notebook
- Build public static dashboard
- Add evidence explorer
- Add correction and methodology pages
