# Contributing

Contributions are welcome when they improve evidence quality, reproducibility, coverage balance or methodological clarity.

## Evidence submissions

A submission should include:

- Source URL
- Outlet and programme
- Publication date if known
- Start and end timestamp
- Exact short excerpt
- Original language
- Translation if used
- Speaker name or role
- Target entity
- Proposed classification
- Explanation
- Evidence tier
- Known uncertainty

## Review expectations

Contributors must:

- Apply the same standards regardless of political direction
- Separate speaker claims from outlet-level conclusions
- Avoid claims about private motive or intent without evidence
- Avoid personal attacks
- Mark machine-generated material
- Preserve meaningful surrounding context
- Disclose conflicts of interest where relevant

## Pull-request rule

A pull request that introduces a named or high-severity finding should ideally receive two approvals before publication.

Examples include allegations of:

- Deliberate fabrication
- Incitement
- Coordinated propaganda
- Criminal conduct
- Knowing deception

The default vocabulary should remain descriptive and evidence-based.

## Data rights

Do not submit downloaded broadcasts, full subtitle files, complete third-party transcripts, confidential records, personal contact details or authentication data.

By contributing original annotations or documentation, you agree to license that contribution under CC BY 4.0. Code contributions are licensed under Apache-2.0.
